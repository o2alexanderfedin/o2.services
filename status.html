Fabric status

What the fabric's bootstrap objects are publishing about themselves, read live.

This page asks you for nothing. No account, no passphrase, no cookie. It only reads, and nothing you do on it can change anything anywhere — the operator's write surface is not reachable from any web page.

The node page is a different page and it does ask. It keeps an identity on your own device, so it asks you to choose a passphrase before it will run anything: that passphrase is what stops whoever finds your device from being able to act as you. There is still no account and no server behind it — the passphrase never leaves your browser, and nobody, here or anywhere, can recover it for you. You can look around that page without choosing one; you just cannot run anything until you do.

Add ?self=https://host (comma-separated for several) to point this page at other objects.
