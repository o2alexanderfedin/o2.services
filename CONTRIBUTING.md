# Contributing

**This project does not accept contributions.**

Pull requests will be closed without review. Patches, diffs, and code suggestions
sent by any channel will not be merged.

This is deliberate, not an oversight:

- The [LICENSE](LICENSE) grants no right to modify the software or create
  derivative works, so it does not authorize a contribution in the first place.
- The project is [dual-licensed](LICENSE-COMMERCIAL.md). Relicensing under
  commercial terms requires the licensor to own or control every right in the
  software. A contribution the licensor does not own cannot be relicensed — one
  merged patch would break the commercial track for that file permanently.

Accepting contributions would require a Contributor License Agreement. There is
no CLA, and none is planned at this time.

## What is welcome

| | |
| --- | --- |
| Bug reports | Open an issue describing what you observed. Do not attach patches. |
| Security reports | Email **af@O2.services** directly. Do not open a public issue. |
| Commercial licensing | Email **af@O2.services** — see [LICENSE-COMMERCIAL.md](LICENSE-COMMERCIAL.md). |

Reporting a bug transfers nothing and grants you no license. Describing a defect
is not a contribution; supplying the fix is.
