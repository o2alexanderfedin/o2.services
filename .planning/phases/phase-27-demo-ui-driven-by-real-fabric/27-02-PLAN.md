<objective>
Port the mockup's design into the demo page and give the page the six-surface shell the
rest of the phase fills. Layout and wording only: **no React, no Babel, no `dc-runtime`,
no `unpkg.com`, no remote font.** The mockup is a `<x-dc>` template rendered by a
vendored runtime that fetches React 18, ReactDOM and `@babel/standalone` from a CDN at
load; the demo is a static-host page with no build-time CDN dependency and it stays one.

Three findings from UI-SPEC section 1.1 are load-bearing here and each is a task
constraint rather than a preference:

1. **The mockup's stylesheet `@import`s `fonts.googleapis.com` on its second line.**
   Porting it verbatim contacts a third party at load, **before consent** — which is
   precisely what the gate promises does not happen. Nothing in the e2e suite catches
   this today: the request assertions filter only `bootstrap.json` and `ws`. This plan
   adds P10, which holds it.
2. **`vocabulary.node.test.ts` bans five words repo-wide — read its `BANNED` list, which
   is the only place they should be written down — and `packages/browser/demo/` is not
   among its `EXEMPT_PATHS`.** The mockup stylesheet's two header comments each use one of
   them in its CSS sense and are exempted **at the mockup's path only**, so the same
   sentence in the ported file is an unexempted violation. Say *custom properties* for the
   `--color-*` and `--space-*` declarations, and reword both header comments on port.
3. **The port is a COPY, not a move.** Both mockup guards have dead-entry checks, so
   deleting or relocating the source directory turns three exemptions dead and reddens
   two guards.

Purpose: land the design and the navigation once, so that every surface plan after this
one adds regions to a shell that already fits, already contrasts, and already contacts
nobody.
Output: `demo.css`, `nav.ts`, a restructured `index.html`, P10 in `built-bundle`, and a
contrast block in `demo-viewport.e2e.test.ts`.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| page load -> third-party host | Any request the page makes before consent is a third party learning a visitor is present, which the gate promises does not happen |
| mockup source -> shipped page | An imported artifact carrying a CDN dependency, a runtime, and plausible literal figures |
| stylesheet -> readable text | A contrast failure is a denial of the information the page exists to convey |

| T-27-04 | Information Disclosure | Remote font `@import` in the ported stylesheet | mitigate | The `@import` is deleted, system stacks replace it, and P10 asserts every pre-consent request is same-origin over the whole request set rather than a filtered slice (Tasks 1, 3) |
