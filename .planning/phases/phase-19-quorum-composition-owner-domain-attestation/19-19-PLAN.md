The independent verification scored criterion 1 **PARTIAL** and the reason is the finding:
**the relay assertion at `quorum-agents.node.test.ts:552-558` cannot fail.**

`bin/agent.ts:91` declares `port` with `default: '0'`, and `:685` passes
`listen: ['/ip4/127.0.0.1/tcp/${port}']` unconditionally. So `canRelay` (`fabric-node.ts:1083`)

(`:627-628`), the intersection reduce starts from `[]`, and `sharedRelay` short-circuits at
`quorum.ts:267`. **There is no value of anything that makes that assertion fail.**

This is the same class Phase 18 shipped — an assertion whose failure was excluded at the type
level rather than merely unlikely. The difference is that this one was caught before the phase
closed, by a verifier that re-derived it from source instead of trusting the summary. 19-08 had
already declared it INCIDENTAL in the file's own header and ledger `M40` records that deleting
rule 2 reddens **only** the in-process fabric. So nothing here is a surprise; what is missing is
the reading the criterion actually asks for — *a job run through `bin/agent.ts`*.

**The fix is one flag and a fixture swap.** The binary cannot express a node that binds nothing,
so make it able to, and then build fabric B from real processes.
</objective>
