# Phase 15 · Plan 02 — the dispatching half

> **Numbers in this plan are configuration choices, not derived claims. Any quantity
> describing runtime behaviour must be measured before it is written down anywhere,
> including in a source comment.**

**Closes (in part):** AUTH-03. This plan makes `RemoteExecutor` attach a chain and makes the
omission a compile error. It does not install an authorizer anywhere — Plan 15-03 does that —
so every dispatch in the repository still lands on `'serves-unauthenticated'` when this plan
finishes, and the suite stays green.

<objective>
`AgentRequest`'s `exec` variant has carried `capability?: readonly Delegation[]` since Phase 4
(`protocol.ts:56-61`), encodes it (`:304-305`) and parses it with every field validated
(`:422-433`). The only caller that has ever populated it is a round-trip assertion at
`distributed.test.ts:628`. `RemoteExecutor.execute` sends `encodeRequest({ kind: 'exec', task })`
with no `capability` key at all (`remote-executor.ts:39`).

This plan closes that. `RemoteExecutor` gains a **required** third constructor argument: either a
per-task chain supplier, `(task: Task) => readonly Delegation[]`, or the named sentinel
`'dispatches-unauthenticated'`.

Required, not optional, and 15-CONTEXT.md decision 3 gives the reason in the project's own
words: `.planning/PROJECT.md`'s Key Decision **"An optional hook with a silent default is a
hole"** (`PROJECT.md:235`) is why this milestone exists, and an optional third argument
reproduces the defect exactly — a `RemoteExecutor` built without one would dispatch
unauthenticated and nothing would fail. `serveAgent`'s **seven hooks** already have that
compile-time proof — one omission case each at `agent-contract.test.ts:52-103`, under a
`describe` that names the count itself at `:42` — while `RemoteExecutor`'s third argument has
none, which is 15-CONTEXT.md Risk 5. This plan makes the two sides symmetric.

Purpose: give the wire slot a producer, and make the absence of one something a call site has to
write down.
Output: a changed constructor, 44 updated call sites, a compile-failure guard mirroring
`agent-contract.test.ts`, a burn-down count for the new sentinel, and an in-process proof that a
minted chain arrives intact and that a refusal precedes execution.
</objective>
