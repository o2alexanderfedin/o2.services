`bin/agent.ts` argv this fixture drives:
  `--dir <d> --port 0` binds a listen address, which is what makes a node relay-capable
  (`canRelay` is derived from the listen list, never configured).
  `--admit-issuer <hex>` repeatable. `--trust-anchor`, `--trusted-issuer` are different flags
  for different subjects and are not used here.
  `--issues-certificates --max-issued-per-window <n>` makes a process a provider.
  `--provider-addr <ma> --user-key <path> --operator-id <id>` enrols.
  `--relay-addr <ma>` repeatable — relays this node asks for a reservation.
  `--peer-addr <ma>` repeatable — peers this process dials once it is up. **This is what makes
  the stranger meet a relay-capable peer it does not ask for a reservation from**, which is the
  exact hole 24-04 found.
  Handshake line on stdout: `peerId`, `multiaddrs`, `relayAdmission`, `certificate`,
  `issuerKey`, `relays`, `pid`, `nodeKey`.

`bin/seed.ts` after 24-06:
  `--dir <d> --port 0 --ws-port 0 --admit-issuer <hex>` repeatable.
  Banner sentinel `Ctrl-C to stop.`; the `relay ` lines carry dialable multiaddrs (take the
  loopback one); the `admits` line is two-armed and the closed arm names the pinned keys; the
  join-URL lines carry the chosen HTTP port.

`BootstrapInfo` (`seed-server.ts`): `{ relayAddrs, seedPeerId, peerAddrs }` where
`peerAddrs = [seedAddr, ...node.reservedPeerIds.map(id => `${seedAddr}/p2p-circuit/webrtc/p2p/${id}`)]`
served from `GET /bootstrap.json` with `cache-control: no-store`.

The two-step provider start, established by `gated-admission.e2e.test.ts` and by
`enrollment-cost.node.test.ts`: a provider's issuer key does not exist until `issuesCertificates`
has been through one start, and a provider restarting on the **same** `blockstoreDir` keeps its
issuer key across a different pid. So a provider that pins its own issuer is spawned twice.

`advertisedBy` — the production rendezvous path, not a getter read twice:
`reader.rpc.request(peerId, encodeRequest({ kind: 'reservations' }))`, answered by
`fabric-node.ts` from `() => node.reservedPeerIds`, a **thunk**. Copy
`admission-agents.node.test.ts`'s helper of that name verbatim, including its docblock's reason.
