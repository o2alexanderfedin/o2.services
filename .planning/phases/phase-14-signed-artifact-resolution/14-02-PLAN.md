# Phase 14 — Signed Artifact Resolution · Plan 02

**Closes (in part):** DET-03, DATA-08
**Wave:** 2 · **Depends on:** 14-01 · **Autonomous:** yes

Carriage, and the demo's own record. Plan 14-01 built a guard that reads
`task.moduleRecord`. Nothing yet puts one there, and nothing carries one across a
wire. This plan closes both, and mints the one signed artifact the browser tier will
need — because Plan 14-03's `bin/seed.ts` imports its trust anchor from `@o2/demo`,
so the anchor has to exist before either wiring plan can compile.

<objective>
Three things a `NameRecord` cannot reach the guard without:

1. **The wire.** `parseRequest`'s `exec` branch already carries one optional field
   alongside `task` (`capability`, AUTH-03's, plumbed and not yet populated).
   `moduleRecord` is the second instance of a shape that already exists once — same
   explicit field-by-field encoding, same "a malformed one refuses the whole frame"
   rule that `parseDelegation` established.
2. **In-process submission.** `JobSpec` gains an optional `moduleRecord` that
   `submitJob` copies onto every `Task` it constructs.
3. **The demo's artifact.** `packages/demo` gains a generated, committed
   `kernel-record.ts`: a signed mapping from a name to the CID of the committed
   `kernel.wasm`, plus the public half of the key that signed it.

Purpose: after this plan a record can be attached, sent, received and read. After
14-03 and 14-04 it must be.
Output: `moduleRecord` on the wire and in `JobSpec`; `KERNEL_RECORD` and
`KERNEL_TRUST_ANCHOR` exported from `@o2/demo`; a build test that checks the record
against the binary rather than taking it on faith.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| peer → `parseRequest` | Every byte of a `moduleRecord` arrived off a wire. It is validated field by field before anything is asked to verify it, on the same terms as `parseDelegation` |
| the repository → a demo tab | The demo's anchor and the demo's artifact have one origin. This closes substitution *by a peer* and closes nothing against the repository itself — stated in the generated file rather than left for a reader to work out |
| `sign-kernel.ts` → the committed record | Run by hand, at build time, by the sole author. Nothing at runtime can produce or alter a record |
