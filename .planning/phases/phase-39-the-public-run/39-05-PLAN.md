## Phase Goal

**As a** project owner, **I want to** send the first invite only after seven conditions hold on a dated
checklist with named evidence for each, and to send invites in stages by region and by cohort slice with
the funnel read between them, **so that** the fabric's headline claim is finally measured on hundreds of
independently-owned devices rather than asserted.

<objective>
Criterion 3: *"Invites go out in stages, by region and by cohort slice, and each stage's go/no-go **reads the
funnel** before the next invite is sent. Staged rollout is **inferred from general release practice and
recorded as inferred**: no named volunteer-computing precedent for staged rollout of a compute cohort was
found, and this criterion does not pretend otherwise."*

A staged public run is exactly the thing that drives the cost that already took this tier down once.

**Measured, and it binds this phase harder than any other constraint.** Durable Object requests are the
binding cost, not Workers requests: on 2026-09-03 the account read **1 100 232 DO requests against 1 000 000
included, on day 3 of the period**, while Workers invocations were **1 966**. Every WebSocket message counts
as a DO request, so the driver is **protocol chattiness per connection — roughly 165 requests per relay
reservation** — and not visitor count. Overage is **$0.15 per million**. Object duration sits at 1 %, so
hibernation works. The free tier's 100 000/day cap took the hosted node down mid-day with Cloudflare error
1027, refused at the edge, the Worker script never running — and **a spending alert would not have caught
it**, because that is a control on money and this was a control on requests. The account is now on the
**$5/month Workers Paid plan**.

The owner's own words in this project are *"У меня нет таких денег"*. So: **a stage that cannot state its
expected request cost before it is sent is a stage that must not be sent** — and the estimate itself has to
be checked against the measurement afterwards rather than trusted, or the second stage inherits the first
stage's error.

Purpose: make RUN-07 executable — stages, a funnel reading between them, and a numeric stop rule.
Output: the arithmetic as a runnable module with a spec, and the runbook that uses it.
</objective>
