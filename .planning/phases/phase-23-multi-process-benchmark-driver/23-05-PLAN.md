# Phase 23 · Plan 05 — Run it, publish it, and hold the published file to its provenance

**Closes:** BENCH-07 criterion 4 in its operational form, and produces the measurement
criteria 1, 2 and 3 are about. **Wave 4. Depends on Plans 23-03 and 23-04.**

<objective>
Everything is built and nothing has been measured. This plan freezes the previous run,
then runs the benchmark and commits what comes out, and it puts a guard on the committed
file first — because criterion 4's second half, *no figure is silently replaced*, is a
property of the artifact, not of the code that generated it. A driver that renders
provenance correctly and a report file that lost half its rungs to a `--quick` run are
indistinguishable from inside the driver.

**The freeze comes first and is not optional.** `main()` rewrites
`.planning/BENCHMARK-RESULTS.md` wholesale and re-measures the memory and real ladders on the
same rungs, so every Phase 8 value is overwritten the moment the run starts. Criterion 4's
second half is met by those values surviving in `.planning/BENCHMARK-RESULTS-2026-07-27.md`,
which nothing regenerates, and by the new report stating the re-measurement — not by a guard
matching the shape of a table row, which passes against any numbers at all.

Three things make this plan different from the four before it. It is the only one that
produces numbers. It is the only one that must **stop and revise a declared parameter** if
the fixture does not behave through the fabric the way it behaved in isolation — the
per-shard figures in the amendment were measured with `WasmExecutor` driven directly, and
through the real transport each shard additionally pays block fetch, canonical
encode/decode and RPC framing. And it is the only one where the honest outcome may be a
curve that is flat: a flat curve is published flat, with the three figures that make it a
finding about the fabric attached.

Purpose: publish, and make the published file checkable.
Output: a frozen `.planning/BENCHMARK-RESULTS-2026-07-27.md`;
`bench-results.node.test.ts` reading the committed report, the frozen artifact and the two
sources that generate the headings; a regenerated `.planning/BENCHMARK-RESULTS.md` and
`.planning/bench/raw.json`; and, if the fixture needed moving, a fourth dated amendment entry
recording that it did and why.
</objective>
