## Phase Goal

**As a** browser visitor arriving from a Telegram message, **I want to** land somewhere that
works, with the copy that brought me there promising exactly what the licensing ruling will
still support a year later, **so that** what I was promised is what I actually get — with the
contribution posture written down before the first outside pull request arrives.

<objective>
Close the **residue** of criteria 3, 4 and 5 — and nothing else.

**What is already discharged, named here so nobody rebuilds it.**

- **Criterion 3 is met in full and is `[x] DEMO-05` in the ledger.** `CONTRIBUTING.md` carries
  all three clauses the criterion names: *"Pull requests are **triaged, never merged**"*, *"the
  fix is implemented **independently of the reported diff**"*, and *"There is no CLA, and none
  is planned at this time."* Each is asserted by name at
  `packages/node/src/licensing-consistency.node.test.ts:163-186`. **Nothing in this plan
  touches `CONTRIBUTING.md`.**
- **Criterion 4 is met for project copy and is `[x] DEMO-06`.**
  `licensing-consistency.node.test.ts:90-160` scans five prose files for
  `\b(always|forever|permanently) (be )?(free|open source)\b` and for six superseded licensing
  terms, exempting a claim only in the sentence that retires it, with an anti-vacuity floor
  (`PROSE.length === 5`, every text over 500 characters).
- **Criterion 5's in-tree half is met** by `packages/node/src/vocabulary.node.test.ts`, which
  scans every file `git ls-files` reports.

**The residue, which is what this plan is.** Both criterion 4 and criterion 5 speak about
**recruitment copy**, and there is no recruitment copy in this repository. Criterion 5 goes
further and names the hazard by hand: *"That guard scans tracked files, so recruitment copy
that lives outside the tree is checked by hand against the same five patterns before it is sent
— an unchecked message is the one a reviewer greps."*

So: bring the message into the tree, where both guards already reach it, and give the
out-of-tree case one command that reads the **same** five patterns rather than a second list of
five that can come to disagree with the first.

Purpose: an absence claim about copy is only worth what its positive control is worth. Every
claim here is planted and watched failing.
Output: one shared pattern module, one checker command, one tracked recruitment document, and
two guards whose corpora now reach it.
</objective>
