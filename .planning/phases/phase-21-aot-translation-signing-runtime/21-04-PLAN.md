# Phase 21 · Plan 04 — a guest a translated artifact can finish a job with

> **Numbers in this plan are configuration choices, not derived claims. Any quantity
> describing runtime behaviour must be measured before it is written down anywhere,
> including in a source comment.**

**Requirement IDs closed by this plan:** AOT-04 (the precondition the roadmap does
not name: *no lifted artifact in existence can complete a job on this fabric*).

<objective>
The roadmap says Phase 21 needs no research because "the gap is that the lift
pipeline never calls `translationCid` and no production node builds a
`WasiExecutor`". That is accurate about those two gaps and silent about a third.

The only real elfconv artifact ever pointed at the executor is a `printf("hello\n")`,
and it necessarily ends `not-dag-cbor` (`wasi-real.node.test.ts:147-171`) because the
fabric's output codec is DAG-CBOR and the guest writes ASCII. That file says so in
its own words: *"Producing a result from a real artifact needs a guest that speaks the
codec … That is a larger piece of work and it is not what AOT-04 asks for."*
**Criterion 3 asks for it.**

The shortest correct route is an **echo**. `WasiExecutor` writes the input block onto
the guest's stdin (`TaskStdin`, `wasi-executor.ts:436`), and that block is
`canonicalCid(value).bytes` — already valid DAG-CBOR (`packages/core/src/job/submit.ts:167`).
A guest that copies stdin to stdout therefore emits the shard's own value, which is
exactly what the hand-written `wasi-echo` fixture does (`fixtures/wasi-fixtures.ts:42-43`).
The property being demonstrated is unchanged; only its provenance is — and provenance
is the whole point of the criterion.

Purpose: without this, Plan 21-05 has nothing to dispatch, and AOT-04's runtime claim
would rest on a fixture written by the same hand as the executor — the shape of every
defect this project has recorded.
Output: `tools/aot/echo-guest.ts`, which builds a guest inside the toolchain image
from C held in this repository and lifts it through `tools/aot/cli.ts`; and a spec
that measures whether the result runs. **This plan can legitimately end in "measured
and not met."** See Risks.
</objective>

## Risks — the one this plan can actually lose to

**The echo may abort, and that is a legitimate outcome of this plan.** The evidence
that it will not is real but indirect: the hello-world lift instantiated, ran `_start`
to completion and wrote bytes (`wasi-real.node.test.ts:147-171`), so the untranslated
ifunc variants were not selected under the emulated auxv. Plan for the possibility
that they are. If the echo aborts, the fallbacks, in order:

1. Drop to raw syscalls with no libc startup at all.
2. Try a smaller input program.
3. If neither works, report criterion 3 as **measured and not met**, with the aborting
   address, in the summary and in `.planning/REQUIREMENTS.md`'s AOT-04 row.

**This ladder is not a plan task and cannot be made into one.** Whether the lifted
glibc startup reaches one of the addresses elfconv left untranslated
(`lift.ts:14-18`) is not decidable before the lift runs, and no test can decide it in
advance — which rung of the ladder applies is itself a measurement. Criterion 3 can
legitimately end unmet here for a reason no amount of fabric work fixes, and the
correct output in that case is the aborting address plus the words *measured and not
met*, not a rewritten criterion and not a hand-written fixture standing in for a
translated artifact.

**Do not substitute a hand-written `.wat` fixture and call it a translated artifact.**
`wasiEcho` already exists and already proves everything a hand-written fixture can
prove; the entire value of this plan is provenance.

## Out of scope

- **A translation cache that consults the key before lifting.** The key is emitted in
  Plan 21-01; nothing looks anything up by it, and no criterion asks for one.
- **Committing the lifted artifact as a fixture.** Opaque binary; the repository
  already refuses this trade for the 659 KB lift subject

- **A guest that computes anything.** An echo is the shortest program that makes a

  additional about the path.
- **Emitting the artifact CID into a machine-readable file beside the `.wasm`.**
  Useful for a build pipeline, asked for by no criterion.
