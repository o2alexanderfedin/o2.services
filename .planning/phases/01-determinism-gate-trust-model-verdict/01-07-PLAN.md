<objective>
Wire the probes and kernel from Plan 01-06 into an executable cross-architecture
measurement: a runner that instantiates each module and canonical-hashes its
output, a measurement script producing one JSON artifact per OS covering all four
runtimes (Node + chromium + firefox + webkit), a diff tool that compares every
probe's hash pairwise across the full matrix, and the GitHub Actions workflow that
runs it all on `ubuntu-latest` (x86-64) and `macos-14` (arm64) on every push plus
nightly. This is DET-04's execution half — the empirical measurement the phase
exists to produce.

Purpose: The verdict (Plan 01-08) is a mechanical function of this harness's own
output. Getting the harness's mechanics right — including the strict requirement
that the NaN-bit-leak probe's result participates in the same pairwise comparison
as every other probe — is what makes the eventual verdict trustworthy rather than
asserted.
Output: `tools/divergence-harness/{run-probe,measure,diff}.ts`,
`.github/workflows/divergence.yml`, `package.json` scripts.
</objective>
