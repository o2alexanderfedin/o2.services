<objective>
Author the divergence harness's test modules (DET-04's probe generation half): five
hand-written WAT probes — four straightforward fresh-NaN generators plus the
load-bearing NaN-bit-leak probe — and one realistic AssemblyScript-compiled float
kernel, each with a build script compiling it to `.wasm` at build time. This plan
does not run the cross-architecture measurement itself (Plan 01-07 does); it
produces the exact byte-identical inputs that measurement will execute.

Purpose: Per CONTEXT.md's locked decision, WAT alone gives exact opcode control but
no compiler realism, and a compiled kernel alone gives realism but no exact opcode
control — neither is sufficient alone. The NaN-bit-leak probe is the harness's
single most important test case: the one no canonicalization scheme (Plan 01-04)
can repair, because its divergence has already left the float domain by the time it
reaches the output boundary.
Output: `tools/divergence-harness/probes/*.wat`, `probes/build.ts`,
`kernel/float-kernel.ts`, `kernel/build.ts`, and their test files.
</objective>
