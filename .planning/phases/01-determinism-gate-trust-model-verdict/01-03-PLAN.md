<objective>
Build the admission-gate scanner (DET-01): a pure TypeScript function in `@o2/core`,
zero platform imports, that walks a WASM binary's sections — including the Code
section as a genuine instruction stream with a length table, not a byte-grep — and
rejects relaxed-SIMD opcodes, atomics/shared-memory opcodes, non-allow-listed
imports, and `memory.initial !== memory.maximum`, naming the offending construct and
its byte offset. This is the phase's single most nontrivial engineering task; it
gets its own plan and its own exhaustive test suite, per the hard constraint that a
byte-grep for `0xFD`/`0xFE` is explicitly disallowed.

Purpose: DET-01 is a load-bearing correctness component — both the publish-time gate
(this plan) and its independent parity check (Plan 01-05, threat T-1-02) depend on
this scanner being genuinely correct, not merely appearing correct on synthetic
single-instruction test modules.
Output: `packages/core/src/admission/{result,sections,opcodes,scan}.ts` and their
test files; `packages/core/src/index.ts` updated to export the public surface.
</objective>
