<objective>
Build canonical-form output hashing (DET-05): a pure function in `@o2/core`, zero
platform imports, that hashes a declared output schema field-by-field after
normalizing NaN bit patterns and signed zero, using `crypto.subtle` — the same
object in Node 24 and every target browser, requiring no reconciliation shim. This
is the comparator the divergence harness (Plan 01-06/07) and, eventually, the
executor's verification path depend on to distinguish genuine cross-architecture
divergence from allocator-residue noise.

Purpose: DET-05 exists specifically to forbid raw linear-memory hashing, which
would misdiagnose allocator residue and struct padding as platform divergence — a
false-positive trap the divergence harness cannot afford.
Output: `packages/core/src/canonical/{normalize,hash}.ts` and their test files;
`packages/core/src/index.ts` updated to export the public surface.
</objective>
