<objective>
Build an independent publish-time admission check using `wabt`/`binaryen` — a
genuinely different code path than the hand-written pure-TS scanner from Plan
01-03 — and prove by automated test that the two agree on every module in a shared
test corpus. This directly closes threat T-1-02: a module admissible to one pass
but rejected by the other is tampering-shaped risk, not a cosmetic inconsistency.

Purpose: DET-02 (a later phase's requirement) depends on the runtime scanner never
silently drifting from what was validated at publish time; this plan is Phase 1's
own test that the two independently-implemented rule-set enforcers actually agree
today, before any later phase builds on the assumption that they always will.
Output: `tools/admission-check/publish-scan.ts`, `tools/admission-check/parity.test.ts`.
</objective>
