# Phase 18 · Plan 04 — The offer answer says how much room there is

> **Numbers in this plan are configuration choices, not derived claims. Any quantity
> describing runtime behaviour must be measured before it is written down anywhere,
> including in a source comment.**

**Closes:** criterion 2c — *placing N shards through `planWithOffers` + `rpcAdmission`
does not over-commit a node past its declared limit.* Implements owner ruling **D2**.

<objective>
Phase 13.1 moved the offer branch from `LocalCapacity.offer` to `LocalCapacity.would`
(`net/src/agent.ts:653-660`), which reserves nothing. That was right — an offer
reservation had no release anywhere on the wire, and the demo's liveness probe
(`{kind:'offer', shardId:'probe'}` on every `computePeers()` call) would have leaked one
slot per peer per call, permanently. The reasoning is recorded at `agent.ts:616-652` and
this plan **does not reopen it**: no shard id is added to `exec`, and no offer
reservation is restored.

What that change cost is stated in the same comment and pinned by a test.
`placeWithOffers` shrinks its pool within one shard only, and `pool` is rebuilt per request
(`placement.ts:169`), so the cross-shard bound *was* the reservation.
`packages/net/src/discovery.test.ts:352` records the consequence in its own words — *"no
longer bounds anything across shards — four land on one 1-slot node"* — with `[only, only,
only, only]` at `:384-389`, zero rejections at `:390`, and `peakInFlight` 0 at `:395`.
**That case is expected to turn red when this plan lands. It is rewritten here to assert
the new bound; it is not deleted and it was not "fixed" early.**

D2 settles the mechanism: the `offer` **response** publishes what the node can run at once
and what it is running now, and the requestor bounds its own placement. Reserves nothing,
so there is no reservation to leak and no expiry to manage. **It is advisory** — a
dishonest requestor can still over-commit — and the authoritative bound never moved:
SCHED-06 makes the `exec` branch refuse for real (`agent.ts:729-730`, released in a
`finally` at `:817`). What D2 removes is wasted round trips, not the bound.

Purpose: give a requestor a figure to bound itself with, and make `planWithOffers` use it.
Output: `NodeCapacity` on every `Admission`, two more fields on the offer frame, and a
cross-shard headroom tally inside `planWithOffers`.
</objective>
