# Phase 22 · Plan 02 — The guard, and the two defects it must catch

**Closes:** criterion 2, in full. Criterion 1's reading is 22-03; criterion 3's gate is 22-04.

<objective>
22-01 built a tracer and proved it can be wrong. This plan turns it into a guard: a verdict, a
sentence a reader can act on, and the two plants criterion 2 names by hand — *"commenting out a
wired call site, or adding a new exported-but-uncalled function"*.

**The naming clause is not decoration.** Criterion 2 asks for the failure to name *"the
unreachable symbol and the barrel it came from, the same way `purity.node.test.ts` names a
layering violation"*, and that file's own comment says why: *"'A violation was found' would leave
a reader grepping for which import, in a package of hundreds."* The corpus here is 581 exports
across eight barrels.

**Read `22-CONTEXT.md` §§ *A proof that cannot fail is not a proof* and *The disposition register,
not an allow-list* before starting.** This plan does not build the register — it must simply not
build something that would make one unnecessary by accident.
</objective>
