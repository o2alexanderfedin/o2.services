**Closes (instrument, first quarter):** the precondition for all three criteria. This plan scores
none of them. It builds the thing the other three read, and it proves that thing can be wrong.

codebase. So the first job of this phase is not to take a reading — it is to build an instrument
whose resolving power is itself measured, because otherwise "passes clean" is a number the
instrument chose.
