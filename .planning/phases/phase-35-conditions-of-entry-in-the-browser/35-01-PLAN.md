# Phase 35, Plan 1 — Conditions of Entry in the Browser

**Goal, verbatim from ROADMAP.md:** *As a browser visitor, I want to see what will run, what
leaves my device and what it costs before anything is fetched, to know the tab is computing
even when it is not the tab I am looking at, and to stop it in a way that drops CPU to zero
and closes the socket the operator is billed for, so that my machine is never working for
someone else without my informed and revocable consent.*

You are executing this with none of the planner's context. Everything you need to start is
below or is named by path and line. Read `<read_first>` on each task before touching anything.

## The five success criteria, VERBATIM from `.planning/ROADMAP.md`

Each clause is load-bearing. Plan and verify against these words, never against a paraphrase —
including the ones in this plan's own task titles.

  1. Opt-in blocks the artifact **fetch**: with consent not yet recorded, a network log of the page shows zero task-artifact requests — not a request that is fetched and then not executed. A reviewer watching network traffic reads a fetch on its own as preparation-to-run, and that reviewer is the audience this gate exists for
  2. A persistent indicator says the tab is computing and is visible while the tab is **unfocused** — a tab-title glyph or equivalent, verified with the tab backgrounded in the three engines this project's Playwright harness already drives. Page-body content alone is watched failing the criterion, because a backgrounded tab shows none of it
  3. The stop control is a hard interrupt of the `Worker.terminate()` class: CPU is measured falling to zero and no in-flight task is allowed to run to completion. A cooperative "stop accepting new tasks" implementation is watched failing this criterion. **The connection the tab held to the hosted tier closes with it**, measured as the duration billing that connection was accruing stopping — on this platform cost is held sockets, not messages, so a stop that leaves the socket open has not stopped anything the operator pays for
  4. Plain-language disclosure is shown **before** opt-in and states four things: what code runs, whose task it is, what leaves the device — with the sovereignty guarantee stated as a selling point rather than a caveat — and what telemetry is sent. A disclosure missing any one of the four fails; a disclosure shown after the opt-in click fails whatever it says
  5. A rough data cost sits beside the CPU disclosure and before opt-in, stated **in bytes for a representative task** and taken from a real run of that task rather than estimated. An international cohort has a mobile-data subset, and a figure nobody measured is the one that gets quoted back

**Requirements, verbatim from `.planning/REQUIREMENTS.md`:** `BROW-06` (opt-in blocks the
artifact **fetch**, not only execution — no task bytes are requested before consent is
recorded); `BROW-07` (a persistent indicator, visible while the tab is **unfocused**, for as
long as any task is in flight); `BROW-08` (a hard interrupt of the `Worker.terminate()` class,
CPU measured falling to zero, no in-flight task allowed to complete, and the connection to the
hosted tier closes with it); `BROW-09` (plain-language disclosure **before** opt-in, stating
four things); `BROW-10` (a rough data-cost disclosure beside the CPU disclosure and before
opt-in, in bytes for a representative task).

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| a visitor's device → any network | The whole phase. A request leaving before consent is the harm, whatever its origin and whatever the page then does with the response |
| an artifact gateway → the tab | Foreign bytes crossing into the tab's blockstore; the fetch is where the consent gate must sit, because a reviewer reads a fetch as preparation-to-run |
| the tab → the hosted tier's billed socket | Duration of held sockets is what the operator pays for on this platform; a Stop that leaves the socket open transfers cost from the visitor to the operator invisibly |
| the disclosure → the visitor's decision | A disclosure that is incomplete, or that arrives after the click, produces a consent record that is not consent |
| a guard → the tree it reads | A zero-request assertion with no positive control, and a plant that cannot redden, both report green for a reason unrelated to the property |
