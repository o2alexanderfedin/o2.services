# 42-07 — A way to look around before choosing a passphrase

**Owner ruling, 2026-09-05.** Asked whether a *look-around* path should exist in front of
the twenty-character passphrase, the owner answered **yes**.

## Why this is not a softening of `42-04`

`PASSPHRASE_MIN_LENGTH` stays at 20 and `signin.ts`'s own header says why: the attacker is
offline holding a disk image, Argon2id at this repository's parameters prices a guess at
roughly two per second per core, and a twelve-character human-chosen password falls to that
in days. Nothing about the seal moves here.

What moves is **who has to pay that price and when**. Today the order is: gate → invent a
passphrase and write it down → see anything at all. The cohort is a few hundred testers in
one group chat and it is spendable exactly once — the same arithmetic criterion 1 of Phase 39
rests on, and the same one SETI@home paid when the move to BOINC lost roughly half of about
600 000 volunteers to added platform complexity alone, with no defect and no bad actor. A
visitor who has just agreed to lend their processor and is then asked to invent and record a
credential before they may see a single figure is a visitor who closes the tab.

So: **look first, register when you want to run something.**

## What a look-around visitor sees, and why it costs almost nothing to build

The page already paints every surface at a *stopped* sentence **before anything runs** —
`index.html:1947-1996`, six `paintSurfaceAbsence(..., 'stopped')` calls at boot, one per
surface. A visitor who is looking around is looking at exactly that state: every card, every
reading, every heading, each one saying in its own words that this tab's node is stopped.
That is honest without a single new sentence per reading, and it is the same rendering a
visitor gets after pressing Stop.

So the whole feature is: reveal `#main` **without starting a node**, say why nothing is
running, and keep the way to the passphrase one press away.

## The four measurements this plan is built on

1. **Auto-start lives inside `revealMain`.** `index.html:3115` is `if (relayAddrs.length > 0)
   await joinNow()`, at the end of the function, and its comment calls it *"the whole of
   'started automatically'"*. **So `revealMain` cannot be reused as-is** — calling it from a
   look-around path would start a node, and `autoStart` without an unlocked identity throws
   `SignedOutError` (`demo/main.ts:269`). The function must be split: visibility and
   discovery and binding, then the start as a separate act.
2. **`mainRevealed` conflates visibility with side effects, and this is a latent defect
   already.** `index.html:3006-3010` early-returns *before* setting `mainEl.hidden = false`.
   Today nothing reaches it twice. Look around → Register → unlock does, and the visitor
   would land on a blank page. The early return must still set the three visibility flags.
3. **Undeclared prose inside `#main` may contain no digits.** The walker at
   `demo-regions.e2e.test.ts:390` is rooted at `#main` and collects every text node with no
   `data-region` ancestor; the digit filter runs Node-side over the whole untruncated node.
   The new notice therefore carries **no digits and no `data-region`** — declaring one would
   be enumerated document-wide by `:367` and would move `UI_SPEC_TALLY`, which is 93 and is
   asserted unmoved by this plan.
4. **The consent gate keeps its position.** `artifact-fetch-gate.e2e.test.ts` waits for
   `#gate` to be un-hidden immediately after load. Look-around sits **after** consent, never
   in front of it, and `signin.ts`'s precedence note is the reason written down.

## Tasks

### T-42-33 — a ninth state, and the prose that says there are eight

`packages/browser/src/signin.ts`:

- Add `{ readonly kind: 'looking-around' }` to `SigninState`.
- Add `readonly lookingAround: boolean` to `SigninInput`, documented as visit-only and
  persisted nowhere — `declined`'s shape exactly.
- Place the branch **after** `unlocked` and **before** the three storage-derived modes.
  Every existing invariant is then untouched: the gate is still first, a refusal is still
  never overtaken by anything, and `unlocked` still wins. What look-around intercepts is
  only the screen a visitor would otherwise have been shown — `login`, `adopt`, `register`.
- A `declined` visitor never reaches it, and the reason is written down rather than left to
  the ordering: revealing `#main` runs `discoverRelays()`, which is a network act, and
  declining is the answer that forbids one.
- Fix the docblock that says **eight** and the sentence *"a ninth cannot be arrived at by
  omission"*. A comment that disagrees with the code loses; this repository fixes it rather
  than leaving it.

`packages/browser/src/signin.test.ts` — new cases, each watched red first:

### T-42-34 — split `revealMain`, and fix the blank page

`packages/browser/demo/index.html`:

- `revealMain` takes `{ start: boolean }`. Visibility is set on **every** call; the
  once-only guard covers discovery, `paintEnrolmentOffer` and the `#join` binding, which are
  the parts that must not run twice.
- The start tail becomes a hoisted `startNode` closure the unlocked arm calls, so *"started
  automatically"* remains **one** code path rather than two that can drift.
- In look-around, `#join` is **disabled with a reason in `#state`**, never left to throw.
  A `SignedOutError` surfacing through the blocked path is a page that looks broken to
  precisely the visitor this task exists for.

### T-42-35 — the surface

`packages/browser/demo/index.html`:

- `#signin` gains a secondary control, *Look around first*, on every arm where an act is
  possible — that is, not in `declined`, where both controls are already frozen.
- `#main` gains `#lookaround-notice` (prose, no digits, no `data-region`) and
  `#lookaround-signin`, *Register or log in*, both revealed **only** in `looking-around`.
  The notice says: nothing is running because nobody has signed in; every reading below says
  so in its own words; choosing a passphrase is what starts a node, and it is one press away.
- The control that enters look-around clears `refusal`, so the ordering above cannot strand
  a visitor who mistyped once behind a screen they chose to leave.

`packages/browser/demo/main.ts` — one page-local `lookingAround` flag, `declined`'s shape,
never persisted.

### T-42-36 — the journey, end to end

`packages/node/src/signin-journey.e2e.test.ts` gains one case:

consent → *Look around first* → `#main` visible, a named stopped sentence readable on a
surface, `#join` disabled → *Register or log in* → `#signin` back → register → unlocked, and
`#main` visible again. **That last leg is measurement 2's plant**: without the visibility
fix it is a blank page, and this is the case that sees it.

Each is applied, watched red, restored by the surgical inverse and verified with `cmp`
against a snapshot taken immediately before planting, with the observed failure text
