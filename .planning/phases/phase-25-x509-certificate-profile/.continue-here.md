# BLOCKING CONSTRAINTS — Read Before Anything Else

> These are not suggestions. Each was discovered through an actual failure in the
> 2026-08-08/09 session, and two of them produced findings that were reported before
> being caught. Acknowledge each before proceeding.

- [ ] **CONSTRAINT: quoted history reads as present tense.** Every ledger row and docblock
      in this repository narrates its own past — *"This row read X until 2026-08-08"*,
      *"The paragraph that stood here said the opposite"*. A `grep` for a stale phrase
      therefore matches the sentence that RETIRED it. **Mitigation, structural:** classify
      on the **leading marker only**, and read the surrounding lines before calling
      anything stale. Bucketing on any occurrence reported 7 requirement rows as
      *Built, not wired* when the true count is 1.
- [ ] **CONSTRAINT: a blanket `node_modules` symlink in a worktree verifies the wrong
      tree.** `node_modules/@o2/*` are relative symlinks into the MAIN checkout's
      `packages/`, so a graph-building guard traces one tree against another tree's
      corpus. **Observed symptom:** `reachability-guard` reported **196** unreachable
      barrel exports against a ceiling of 67 and called `core/submitJob` unreachable.
      **Mitigation, structural:** build `node_modules` by borrowing third-party packages
      by symlink and repointing every `@o2/*` at THIS worktree's `packages/`. With that
      fixed the same guard passed 20/20, no code changed.

**Do not proceed until both boxes are checked.**
