# 4. THE FIVE DEFECTS WORTH REMEMBERING

Every one was invisible to a fully green suite. That is the pattern, not a coincidence.

1. **`PeerVerifier` cached a verdict for the life of a connection**, so a node that enrolled
   after a peer connected was excluded by that peer permanently -- with a *correctly named*
   refusal the whole time, which is why nothing reported it.
2. **The anti-race guard I then wrote was unmeasured**, and probing it found a second real
   defect: the generation counter was per-peer, and `#onDisconnect` deletes the peer's entry,
   so an ask issued before a disconnect collided with one issued after the reconnect. A stale
   refusal could overwrite a fresh acceptance.
3. **`combine.ts` reported a full local disk as "every executor in the fabric has vanished."**
   Measured: 4 executors, 4 combine requests, 4 local writes, every executor marked failed.
4. **EAGAIN was reported as `docker-unavailable`** -- a host that could not fork, described as
   a host without Docker. The obvious diagnosis (timeout too tight) was **refuted by
   measurement**: spawn max 456 ms at load 42-54 against a 5,000 ms budget.
5. **The pi(10^6) oracle is blind to a real coverage bug**, and so is the "same total at 4 and
   8 shards" cross-check, because 10^6 minus 999983 is 17, so an uncovered tail of at most 7
   numbers contains no prime. **A round-number oracle sits in a prime desert.** Only the
   low-bound sweep catches it.

# 5. LESSONS THIS SESSION PAID FOR

1. **Do not pipe a command into another and read the second one's status.** I ran
   `npx tsc --noEmit | head -3; echo $?`, read `head`'s zero, and pushed a type error -- in a
   repository whose standing rule is *never trust an exit code as evidence*.
2. **A gate you run but do not read is not a gate.** I ran the vocabulary guard, watched it
   fail, and committed anyway, because the check and the commit were on separate lines.
3. **An intermediate with all the trappings of a finished artefact is indistinguishable from
   one.** I published a draft of the article because it already had the title, subtitle,
   standfirst and table of contents. The real final arrived 44 minutes later.
4. **A worktree agent is created from the DEFAULT branch, not yours.** It hit four of six
   agents. The symptom is silent and misleading: every plan citation reads as stale and the
   natural conclusion is "the plan is wrong". Always run
   `git merge-base --is-ancestor <intended> HEAD && echo OK` **first**.
5. **A killed agent can leave a planted mutation in the shared working tree.** Found
   `egress === 'holds-no-registrations' || true` -- an always-true condition disabling
   sovereign holds entirely -- in no commit and no branch. `tsc` caught it on merge.
   **Check `git status` before believing any suite result.**
6. **Do not hand-roll a poller for work the harness already notifies you about.** I left one
   spinning for 1h17m waiting for a string I had personally filtered out of the file it was
   watching.
7. **A plant that does not redden may be an unfaithful plant, not a sound test.** One agent's
   first attempt left a hoisted `const` above the code it moved; made faithful, it reddened.
8. **Plan proofs keep being wrong -- seven phases running now.** 18-05's *sole* stated
   regression bar reddened **nothing**: the arm 60 call sites depend on was protected by no
   test at all.
