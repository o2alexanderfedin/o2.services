# BLOCKING CONSTRAINTS — Read Before Anything Else

> Each was learned through an actual failure or an explicit owner correction.
> Acknowledge every one before proposing work.

- [ ] **ALL NODES HAVE EQUAL FUNCTIONALITY.** No tier, no class, no lesser node. Every
      node executes tasks, holds blocks, serves records, hosts reduce combines, and
      takes quorum slots on identical terms. **The only difference is discovery**: a
      browser cannot bind a listening socket, so it cannot be a seed a newcomer dials
      cold and must be found through a relay that can. Once connected, peers are
      indistinguishable.
      **Structural mitigation:** if a decision keys on *what kind of node* something
      is, it is wrong. The only legitimate use of `discoverability` is
      shared-dependency analysis over the discovery graph. The owner stated this three
      times because the first two applications were too weak — the words were changed
      while `backbone`/`edge` survived as classes.

- [ ] **Do not reintroduce static determinism analysis.** An admission gate parsing
      WASM instruction streams was built, hardened, fuzzed, then deleted (1,214 lines,
      `afb3cad`). Divergence is *detected* by byte comparison, never *predicted*.
      **Structural mitigation:** the comparison in `job/verify.ts` is the mechanism.

- [ ] **Verification never spans different implementations.** It compares the *same*
      `moduleCid` on independent nodes.
      **Structural mitigation:** `executeVerified(task, executors)` takes one task
      with one module.

- [ ] **Do not write an allow-list for host imports.** `WebAssembly.instantiate`
      already refuses any import the host does not supply, and names it.

- [ ] **The kernel must never require `crypto.subtle`.** A LAN origin is not a secure
      context. `multiformats/hashes/sha2` uses WebCrypto and silently broke every CID
      on any non-localhost page — while the node still *started*, so it failed at the
      first block rather than at join. Hashing is `@noble/hashes`, pure JS.
      **Structural mitigation:** `insecure-context.browser.test.ts` deletes
      `crypto.subtle` and requires hashing to survive. Import-scanning cannot catch
      this class of bug.

**Do not proceed until all boxes are checked.**

## Critical anti-patterns

| Pattern | What happened | Prevention |
|---|---|---|
| Prediction instead of detection | Tried to prove statically that a computation could not diverge, rather than running it twice and comparing bytes. Pulled hardware-level reasoning into a job scheduler. | Before adding analysis, ask what the existing comparison already catches. |
| Reimplementing the platform | Hand-wrote an import allow-list, a WASM validator, and a `ComponentLogger` that crashed every dial with `log.newScope is not a function`. | Test whether the runtime already does it, in a throwaway script, first. |
| Applying a correction to the words only | Told browsers are equal peers, I rewrote comments but kept `backbone`/`edge` as classes and left the quorum rule discriminating on them. Needed a second correction. | After a design correction, grep for the *mechanism*, not the vocabulary. |
| Believing my own summary | A table row read "3 servers behind one relay → refused". Sounded right; was both mis-worded *and* concealed a real false positive. | Restate rules as concrete tables and probe each row. This found three bugs this session. |
| Trusting an unfalsified check | Phase 1's opcode table had 6 of 18 entries wrong — a false negative in a security gate. | Every new checker gets a planted violation before it is trusted. |

<decisions_made>

- **All nodes equal; only discovery differs.** See the blocking constraint.
- **A seed contributes no discovery dependency**, whatever relays it advertises
  through. Only a node whose *sole* discovery path is a relay depends on it — so two
  certificates with identical `relayIds` get opposite quorum verdicts.
- **Attestation strength is derived, never declared**: `owner-attested` /
  `owner-domain` / `independent`, computed from certificates. Owner-domain and
  independent both show two replicas, so the count cannot distinguish them and the
  label must travel with the result.
- **Disagreement is reported, never voted on** — in execution, in reduce, and in
  quorums. At R=2 there is no majority anyway, and voting converts "something is
  wrong" into "the majority was right".
- **Sovereignty is structural**: `planPlacement` narrows to the owner's nodes before
  load is consulted; no branch widens it.
- **Derive topology, never agree on it**: the reduce tree is a pure function of sorted
  partial CIDs — zero messages, no leader, no consensus. HRW ranking *is* the fallback
  list. Repair is recompute from CIDs, not state transfer.
- **Associativity is the reduce contract; commutativity is not** — an earlier comment
  claimed both and justified it wrongly.
- **Relay capacity is capped by inbound limits, not reservations.**
  `INBOUND_CONNECTION_THRESHOLD` is 5 **per host** and
  `MAX_INCOMING_PENDING_CONNECTIONS` is 10, both below the 15 reservation default.
  Per-host binds in production too — every volunteer behind one NAT shares the budget.
- **A relayed circuit cannot carry a job.** The relay is a signalling channel; the data
  path is WebRTC.
</decisions_made>

## Environment notes

- **Node 23.11.0 is the host runtime and is not LTS.** Outside vitest's declared range
  (`^20 || ^22 || >=24`), so every install prints `EBADENGINE`, and
  `packages/node/src/bin/seed.ts` relies on experimental native type stripping.
  Everything passes; `STACK.md` specifies Node 24.
- **Test file suffixes are load-bearing.** `*.browser.test.ts` browser-only,
  `*.node.test.ts` Node-only, `*.e2e.test.ts` drives Playwright itself and runs with
  `fileParallelism: false` — four of them each launch a Chromium, a relay and a Vite
  server, and running them in parallel produced a flake that looked like a WebRTC bug.
- **Vite `optimizeDeps` pre-bundling must stay on.** Several libp2p transitive deps are
  CommonJS (`netmask` via `@libp2p/utils`); `noDiscovery: true` breaks the page with
  `does not provide an export named 'Netmask'`, which reads like a missing module.
- **The seed server needs `allowedHosts: ['.local']`.** Vite allows only localhost and
  IP literals by default, so the `.local` URL it prints was rejected — and IP-only
  tests could never have caught it.
- **Chromium under automation never reports a page as hidden.** `bringToFront()` fires
  no `visibilitychange`, headless or headed, and CDP has no visibility override.
- **Playwright browser-cache skew recurs**: `npx playwright install chromium`.
