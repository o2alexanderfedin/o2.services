# WHAT WAS DONE — 22 bugs found, fixed, and independently verified

A seven-lens hunt found 22 bugs (4 duplicates merged). Every one was adversarially refuted before
earning a fix, then fixed via an Emergent Design session (3 rival designers, blind to each other,
judged and synthesised), TDD implementation, and a separate verifier that plants the deletion
which should break each new test.

**Three criticals, each reproduced before the fix and re-verified after:**

| | what it was |
|---|---|
| B01 | RPC replies correlated by **id alone** — any peer could answer a request it was never sent. Reproduced a **forged quorum** through the real `executeVerified`: `{status:'agreed', agreeing:['honest','evil']}` while the honest result never appeared. Fixed by keying `#pending` on **(destination, id)**, so a forged frame misses the map and falls into the pre-existing `entry === undefined` return — the honest entry stays alive. |
| B02 | `serveAgent`'s exec branch released an `EgressGuard` hold it never took, so **one unauthenticated public exec stripped a sovereign payload's hold** — measured, 132 raw bytes on the wire with an empty manifest. Fixed by making a hold a **value** (`EgressHold`) instead of a name, and **deleting `release(label)` entirely** so "release a hold you did not take" has no spelling. |
| B03 | A **52-byte looping WASM module** permanently wedged an unauthenticated node — `timeout 15` had to kill the process. Fixed with a wall-clock bound on **both tiers at once**. |

Full list B01–B22 with evidence and the fix rationale lives in the workflow output; the triage
detail files are at `<scratchpad>/BUGS-group-{1,2,3,4}.json`.

**Notable TRIZ outcome:** B10's commit-reveal check compared a value with itself. A rival argued
the ideal fix was **deletion, not repair**, and the judge took it — `855cdf5`.

# COST CALIBRATION — read before running another workflow like this

The 22-bug fix took **4h28m**. Measured cause: **34 full-suite runs at ~5 min each ≈ 2h50m**, and
agents did 155 targeted runs too, so they knew how — but the finish condition *"full suite no worse
than it started"* made a full run the natural last step for every agent.

Two harness lessons:
- **Give the full-suite duty to the verifier once per group**, not to every agent independently.
- **Scale ceremony to severity.** Three rival designers ran for all four groups including group 3,
  which is four `low` bugs — a three-way design contest over `expect(x).toBe(x)` is waste. Roughly
  an hour went there and maybe a third of it earned its keep.
- The `Pyramid` phase declared in `meta.phases` had **no agent assigned to it**, so the progress
  display showed a permanently empty box for work that was really happening inside the implementers.
