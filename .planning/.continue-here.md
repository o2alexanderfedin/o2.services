## Five rulings taken this session, all recorded in the tree

**The signing triangle.** Two legs existed — the code a node runs is signed by the publisher and
verified against pinned `trustAnchors` (Phase 14); the node's certificate is signed by the provider
and verified against `trustedIssuers` (Phase 17). **The third was missing and now exists**: a node
signs its result with the `nodeKey` its certificate carries. Agreement was previously attested by
transport authentication only — Noise proves peer X sent a frame, but that proof is not
transferable. Now a third party holding **only the provider's public key** can verify a result came
from a node that provider enrolled, running code that provider published.

**The combine result is signed too.** Signing `exec` alone would have left a map/reduce job ending
with signed map results feeding an **unsigned aggregation** — precisely the half `PROJECT.md`
claims is the verified one.

**NO BLOCKCHAIN, and revocation is non-renewal.** No shared revocation list, no global reputation
score, no consensus round, no append-only shared log. Trust is pinned per verifier. **Certificate
lifetimes are NOT part of the cost argument** — an earlier draft called for short ones and that was
over-engineering: the attack radius is too small. N sybils under one operator buy exactly one
quorum slot, because `composeQuorum` enforces anti-affinity by `operatorId`.

**VER-03 asks for eclipse resistance, not backbone nodes.** Reworded 2026-08-03; the property is
unchanged and the bar was not lowered. Its rationale clause always read *"so eclipsing a quorum
requires a backbone compromise"*, and shared-dependency analysis is the cardinal rule's
named-legitimate way to express it.

**The quorum is the default and it is OPTIONAL.** `redundancy: 1` composes none. A public shard at
`redundancy >= 2` that cannot compose one **degrades** — runs at available redundancy, is marked
`degraded`, carries the composer's own reason, and reports the weaker strength. Only a caller
setting `JobSpec.onQuorumShortfall: 'refuses-the-shard'` gets a refusal.
