# BLOCKING CONSTRAINTS — Read Before Anything Else

> Each was discovered through failure **in the 2026-08-24 session**, not predicted.
> Acknowledge each before proceeding.

- [ ] **A plant that reuses the value it tests cannot fail.** Two cases were written this
      session whose assertions were expressed in terms of the constant under test. Both went
      **green** under a plant that inverted the behaviour. Write the expected number as a
      **literal**, assert the constant separately, then plant and watch it redden.
- [ ] **A type or option declaration is not behaviour.** Three consecutive wrong answers came
      from reading `@libp2p/kad-dht`'s options type. The class really does declare fields the
      implementation ignores. Run it before writing it down.
- [ ] **`$?` after a pipe is the pipe's exit code.** `git merge --ff-only … | tail -2` printed
      `fatal:` and the captured status was `0`. Read the exit code on the line **immediately**
      after the command, no pipes.

**Do not proceed until all boxes are checked.**

## Critical Anti-Patterns

| Pattern | How it manifested | Severity | Prevention |
|---|---|---|---|
| Self-referential assertion | `expect(f(start + span * RENEW_AT))` — plant moved both sides, stayed green | blocking | Literal expected value; assert the constant on its own line |
| Declaration read as behaviour | Provider-record expiry answered 48 h, then 24 h, then "never" — all from types | blocking | A behavioural test that reddens when the behaviour is absent |
| Exit code through a pipe | `FF-EXIT=0` while git wrote `fatal: Not possible to fast-forward` | blocking | `EXIT=$?` on the next line, never after `\|` |
| Substring status detection | `REQUIREMENTS.md` miscounted **twice, in both directions** — 8 open, then 7, actually 4. Rows say "Formerly **Partial**" and put "Done" deep in the text | advisory | Read the word the status cell **begins** with |
| Frontmatter read as the verdict | Phase 19's `score:` says 4/5; line 1724 of the same file says `Score 4/5 → 5/5`. Verifiers here **append** amendments | advisory | Read to the end of a VERIFICATION file before scoring it |
| Filename sort trap | `13-VERIFICATION.md` (0/3, superseded) sorts after `13-VERIFICATION-2.md` (3/3, live); a `*VERIFICATION.md` glob misses the live file | advisory | Glob `*VERIFICATION*.md` and check `superseded_by:` |
| Eliminations mistaken for a cause | Ten sound eliminations were assembled into one false claim — "any async datastore hangs enrolment". It was falsified in four arms | advisory | An elimination says what a cause is **not**. Only varying the suspected property says what it **is** |
| Inference reported as measurement | Said STATE.md was "cut from 2 397 lines to 17" — read off a preview. It was 2 222 | advisory | Measure the thing you are about to assert |
