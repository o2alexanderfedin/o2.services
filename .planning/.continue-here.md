# BLOCKING CONSTRAINTS — Read Before Anything Else

> Each was learned through an actual failure or an explicit owner correction.
> Acknowledge every one before proposing work.

- [ ] **ALL NODES HAVE EQUAL FUNCTIONALITY.** No tier, no class, no lesser node.
      **The owner has stated this four times.** The fourth was right again:
      `RelayNode` was a class that *structurally could not compute* — no blockstore,
      no executor, no `RpcEndpoint`, never called `serveAgent` — while `FabricNode`
      could bind a socket and never relayed. `relay-node.ts` is deleted and relay
      capability is *derived* from binding a listening address. **The only difference
      is discovery.**
      **Structural mitigation:** if a decision keys on *what kind of node* something
      is, it is wrong. Grep for the mechanism, never the vocabulary. Three of the four
      corrections were absorbed as renames; only the fourth removed the class.

- [ ] **DEMO-04: no deploy workflow file may exist in the repository at all** —
      absent, not disabled. Enforced by `disclosure-gate.node.test.ts`, which checks
      by content so relocating a workflow does not evade it, and forbids any
      publishing script. `build:demo` builds and publishes nothing.

- [ ] **Vocabulary discipline**, enforced repository-wide by `vocabulary.node.test.ts`
      with reasoned, auditable exemptions. It matches `earn` inside `learning`.
      **The NUL-byte hole is closed** — a file containing a NUL is skipped only if its
      extension is a declared binary; anything else fails by name.

- [ ] **Do not reintroduce static determinism analysis.** Built, hardened, fuzzed,
      deleted (1,214 lines). Divergence is *detected* by byte comparison, never
      predicted. The Phase 10 ELF pre-screen is permitted because it predicts whether
      a *toolchain* can consume an input — being wrong costs a failed build, not a
      wrong answer. Do not let it drift.

- [ ] **Do not write an allow-list for host imports.** `WebAssembly.instantiate`
      already refuses any import the host does not supply, and names it. The pinned
      WASI surface is a *replacement*, not a filter.

- [ ] **The kernel must never require `crypto.subtle`.** A LAN origin is not a secure
      context. Hashing is `@noble/hashes`, pure JS.

- [ ] **Never trust elfconv's exit code.** It is `0` on binaries it could not fully
      translate — 174 addresses on a hello-world. Measure the produced module.

**Do not proceed until all boxes are checked.**

## Critical anti-patterns

| Pattern | What happened | Prevention |
|---|---|---|
| Prediction instead of detection | Tried to prove statically that a computation could not diverge, rather than running it twice and comparing bytes. | Before adding analysis, ask what the existing comparison already catches. |
| Applying a correction to the words only | **Four times.** Told all nodes are equal, I renamed things while `backbone`/`edge` survived as classes — most recently as `RelayNode`, a node that could not compute. | After a design correction, grep for the *mechanism*. Ask: what construction path still yields a node that cannot do X? |
| **Fixtures written from the same understanding as the code** | Every WASI execution test used hand-written fixtures built to match the executor's assumptions. The premise about real translated output was an assumption in three comments until a real artifact was finally pointed at it. | If a claim is about the outside world, test it against the outside world. `elf.real.node.test.ts` and `wasi-real.node.test.ts` exist for this. |
| Writing the anti-pattern already in this table | Phase 7's disagreement test wrapped assertions in a condition that could never be true. Phase 10 repeated the shape: `cache-key.test.ts` had only relative assertions. | **Mutation-test every new guard.** Conformance vectors are hardcoded literals, never computed. |
| **A guard that reports itself healthy** | `wasi-executor.test.ts` carried raw NUL bytes, so the vocabulary guard skipped the whole file. Its own planted-violation tests kept passing, because they scan synthetic content rather than the tree. | A guard needs a test that its *coverage* is what it claims, not only that its *matcher* works. |
| **Identity where behaviour was meant** | `PINNED_WASI_FUNCTIONS` checked `pinned[name] !== shim[name]`, which a replacement returning the wrong value satisfies exactly. `undefined` from a socket call coerces to `0` — ERRNO_SUCCESS. | Assert the value, and spell constants as literals rather than importing the same one the implementation uses. |
| A documented bound that is not enforced | The churn header promised a bounded wait and never read `expiresAt`. `BootstrapInfo.seedPeerId` promised a lone phone a peer while that node listened on plain TCP. | Whenever a comment states a guarantee, grep for the mechanism. |
| Asserting the attribute, not the screen | `#bar { display: flex }` outranks `[hidden]`, so the always-visible bar was always visible. Every test asserted the attribute, which was always correct. Found on a phone. | `isVisible`, never `getAttribute('hidden')`. |
| A substring match against a structured string | `address.includes(peer)` matched the *relay's* id inside every circuit address: `dialed: []`, `failed: []`, nothing attempted, no error. | Parse the component. Treat "nothing attempted **and** nothing failed" as a signature worth asserting against. |
| A fake faster than the real thing | Phase 7's hang, unexamined disagreement and OOM spin were all invisible to a microtask-resolving fake. | Any timing claim needs a real endpoint. |
| A unit living in a name | `grossNodeSeconds` held bytes. | Rename rather than document. |
| **"Was not run" is not "works"** | DEMO-01's multi-machine half was about to be closed by reasoning. The owner ran it and found two defects the whole e2e suite had missed. Phase 10's CLI had never been executed once. | Run it. |
| Every multi-tab test dialling from the harness | Nine e2e tests exercised two tabs; not one could have caught that tabs never find each other. | A test that supplies the thing under test proves nothing about it. |

### Phase 10, and what running it produced

A statically-linked AArch64 binary is a fabric artifact. `npm run aot:lift --
/tmp/ecvout/elf/hello_static` ran to completion for the first time: 93.6s, 5.65 MB,
`aarch64-wasi32`, verdict **RESERVATIONS**, exit 2, 174 untranslated addresses named,
both blind spots printed next to the success.

The phase's finding is that **elfconv exits 0 on that input**. Two greps must agree
before the untranslated count is called evidence.

A real artifact reached the executor for the first time, and the ABI held exactly. It
also showed that a `printf("hello\n")` imports `clock_time_get` and `poll_oneoff` —
glibc's stdio pulls them in unasked — so clock pinning is load-bearing immediately,
not theoretically.

The V8 code cache does not happen: 72B across three visits at 4.8 MB, against a 2 MB
JavaScript cache in the same profile and a `--v8-cache-options=none` calibration
reading the same 72B.

<decisions_made>

- **All nodes equal; only discovery differs.** Structural: one Node-side class, relay
  capability derived from binding a listening address.
- **Ask, never classify.** Whether a peer computes is established by an offer probe.
- **Consent is a value, not a check.** `GrantedConsent` is minted only by
  `grantConsent`; a caller without one fails to compile. No test-only bypass.
- **Cooperative stopping cannot exist for WASM.** A synchronous `run()` admits no flag.
- **A metric publishes its own blind spot.** A node that cannot reach a peer cannot
  report that it cannot reach a peer.
- **Overlapping views merge by maximum, never by sum.**
- **Chromium throttles timers in a background tab** (measured: 400 ms → one tick/s).
- **`exhausted` and `budget` must stay different answers.** One is a proof; the other
  is a shortage of compute.
- **Never trust elfconv's exit code.**
- **Same-host reproducibility is not reproducibility.** Two lifts here are
  byte-identical; elfconv iterates a pointer-keyed `std::unordered_map` and a
  `std::set<BBBag*>`, whose order is an address-space property.
- **An unmet criterion is reported unmet.** AOT-05 is a measured negative with two
  controls, not a pending checkbox. A criterion that can only be reported as met is
  not a measurement.
</decisions_made>

## Environment notes

- **Test suffixes are load-bearing**: `*.browser.test.ts`, `*.node.test.ts`,

- **The elfconv container image is pulled** (`ghcr.io/yomaytk/elfconv:arm64`,
  6.08 GB, digest `sha256:22a404f3…`). **Its `ENTRYPOINT` is
  `["/bin/bash","--login","-c"]`, so `docker run … bash -lc '…'` runs nothing and
  exits 0** — the script must be one argument.
- ELF fixtures at `/tmp/ecvout/elf/`, wasm artifacts at `/tmp/ecvout/r1|r2|strip|br/`.
  Neither survives a reboot; every test skips cleanly without them. Regeneration
  recipe is in `elf.real.node.test.ts`'s header.
- **Running the demo across devices:** `node packages/node/src/bin/seed.ts` prints a
  `.local` URL and a QR code. Restart it after any change to `seed-server.ts`.
