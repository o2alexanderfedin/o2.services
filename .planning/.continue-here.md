## STANDING CONSTRAINTS (`CLAUDE.md`'s Conventions carries these with the cost that bought each)

- **Never trust an exit code you did not read directly.** `EXIT=$?` on the very next line, no
  pipes, no trailing `tail`. This trap made a **refused commit report `EXIT=0`** twice this session.
- **Never `git commit -F -` from a tool shell** — the heredoc binds to a trailing command and git
  blocks reading a message from a socket with no writer, holding `.git/index.lock` against every
  agent. Diagnosed by measurement: no children, fd 0 a unix socket, 0.0% CPU, and
  `COMMIT_EDITMSG` **older than the lock**. `SIGTERM` to the git process alone released it in 1 s.
- **Apply-run-restore each plant inside ONE shell invocation** so a kill cannot leave one live. An
  agent killed mid-flight left `PLANT 20-04-C` in `submit.ts`, which had removed the only bound on
  the re-dispatch loop. **After any abrupt agent death, `git diff` production files FIRST** — a
  plant is uncommitted by construction, invisible to `git log`, and looks exactly like work.
- **Commit with explicit paths**, never bare; verify with `git show --stat`. When another agent has
  staged work in a file you must commit, build the commit through an isolated `GIT_INDEX_FILE`.
- **Prefer comparative readings to absolute ones**; **measure the process, not the machine**
  (`/usr/bin/time -p`, `(user+sys)/real`). Load average lies — 0.34 share at load 226.
- **Cite by grep-able symbol, never line number.** 41 of 46 citations had rotted; all now symbols.
- **A proof that cannot fail is not a proof.** Plant, watch it redden, record the observed text.
- **`--reporter=json` is not a valid span instrument** for a file whose hooks sit above its first
  case. Cross-check with solo `/usr/bin/time -p`. The procedure is in `MEASURED_NODE_SPANS`.
- **Do not run `gsd-sdk query state.*`** — `state.advance-plan` printed a parse error **and wrote
  `STATE.md` anyway**. `STATE.md`'s own comment says of three prior corrupters *"None of them
  errored"*; that diagnostic is now false. `roadmap.analyze` returns zero phases; derive by hand.
- **Do not kill or signal any process you did not start.** An agent fired `pkill -f "clang++"` at
  an unrelated LLVM build under `~/Projects/transpilers/cpp-to-rust`. It did not take effect and
  was reported unprompted, but it must not recur.
