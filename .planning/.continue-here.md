# 3. THE FIVE THINGS WORTH REMEMBERING

1. **A test can pass against the wrong composition.** 18-09's e2e passed 5/5 with the
   *visibility* governor wired to the executor instead of the composed one — every
   advertised number was right while the tab ignored the user's cap. `capacity()` reads the
   cap governor directly; only `activity().dutyCycle`, which reads the *executor's* own
   governor, can tell the two apart. **Plant against the reading, not the number.**
2. **Wrapping a governor bypassed its accounting.** `GovernedExecutor` called the wrapper's
   `yieldSlice`, so `VisibilityGovernor.sleptMs` stayed 0 while the pacing was perfectly
   correct, and BROW-03 went red on `expected 0 to be greater than 0`. `yieldSlice` now
   delegates to the environment when the environment binds. **An instrument that stops
   being written is indistinguishable from a throttle that stopped happening.**
3. **The first hypothesis was sound and wrong.** That failure looked exactly like the
   admission coupling (`floor(8 × 0.05)` → 1 slot). Removing the coupling did not fix it.
   The `ownDutyCycle` doc records that the supporting measurement came back **negative**
   and that no test currently fails when the distinction is collapsed.
4. **Eighteen tests reported green by reporting nothing, for weeks.** Their fixtures lived
   in `/tmp`. A conditional guard cannot report its own absence — something unconditional
   has to, and `elf-fixtures.node.test.ts` is now that thing.
5. **Fixing D21 broke `lift.node.test.ts`.** Restoring 17 tests added real CPU, and six
   cases went red with `docker-unavailable` on a healthy host. Raising the budgets was
   wrong and was reverted. The defect was that the retry wrapper handled
   `host-cannot-spawn` but not a daemon that never answered — the same transient condition
   under two labels. `docker-not-answering` is now split out and retried.

# 4. LESSONS THIS SESSION PAID FOR

1. **I read a piped exit code as the command's own, again.** `git commit … | tail` reported
   `EXIT: 0` for a commit the guard had **refused**. This is written in this file's own
   history as a rule and I broke it anyway. Never pipe a command whose status matters.
2. **I asserted a convention without checking it.** "This repo already commits 12 MB of
   binary fixtures" — it does not. They are gitignored under an explicit rule: *an opaque
   artifact in the repository is worse than one reproducible from its source.* `du` showed
   me the disk; `git ls-files` was the question I should have asked.
3. **I reported "2 skipped" four times before anyone asked what they were.** They were 18,
   and they were deficiency D21. A skip looks like a pass from any distance.
4. **A load gate that samples only before the work is a lagging indicator.** The suite
   began at load 5.20, `transport-bounds` read 51 MB against a 40 MiB threshold, and the
   gate had already passed. It now samples after the reading too.
5. **Plan citations were stale again, both of them.** 18-09's plan cited
   `browser-node.ts:885-894`; the handoff's own correction cited `914-921`; the real site
   was `831`. Grep for the mechanism.
