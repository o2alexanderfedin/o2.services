# BLOCKING CONSTRAINTS — Read Before Anything Else

> These are not suggestions. Each was discovered through actual failure this session.
> Acknowledge each one explicitly before proceeding.

- [ ] **CONSTRAINT: Do not reintroduce static determinism analysis.** An admission
      gate that parsed WASM instruction streams to prove modules could not diverge
      was built, debugged twice, hardened, fuzzed — and then deleted entirely
      (1,214 lines, commit `afb3cad`). Verification is a byte comparison of the same
      module run on two nodes; divergence is *detected*, never *predicted*.
      **Structural mitigation:** if a plan proposes inspecting module bytes for
      determinism, stop. The comparison in `job/verify.ts` is the mechanism.

- [ ] **CONSTRAINT: Verification never spans different implementations.** It compares
      the *same* `moduleCid` executed on independent nodes. Cross-implementation
      ("N-version" in the classical sense) comparison is out of scope.
      **Structural mitigation:** `executeVerified(task, executors)` takes one task
      with one module. Any design that dispatches differing code for comparison is
      wrong by construction.

- [ ] **CONSTRAINT: Do not write an allow-list for host imports.**
      `WebAssembly.instantiate` already refuses any import the host does not supply
      and names it. A hand-written allow-list reimplements V8.
      **Structural mitigation:** the import object passed to `instantiate` *is* the
      allow-list. There is a test asserting a module importing `env.now` fails.

**Do not proceed until all boxes are checked.**

## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| Prediction instead of detection | Tried to prove statically that a computation could not diverge, rather than running it twice and comparing bytes. This is what pulled hardware-level reasoning (x86 vs ARM NaN sign bits, relaxed-SIMD, opcode arity tables) into a job scheduler. | blocking | Before adding any analysis, ask what the existing comparison already catches. If the answer is "this", do not build it. |
| Reimplementing the platform | Hand-wrote an import allow-list and a WASM validator that V8 already provides. | blocking | Test whether the runtime already refuses the thing, in a throwaway script, before writing a checker. |
| Ceremony over deliverable | A blocking roadmap phase, 8 plans, 4 waves, a 656-line research doc, and a threat model were produced to answer a question the WASM spec settles in one sentence. | blocking | For any proposed phase, first ask whether a five-minute experiment or a spec lookup answers it. Phase 1 was deleted for exactly this. |
| Guessing binary-format constants | The `0xFC` immediate-arity table was written from memory; 6 of 18 entries were wrong and five caused the walker to swallow the next opcode — a false negative in a security gate (`6eba71d`). | advisory | Fetch the spec for wire-format constants. Never recall them. (Moot now — that code is deleted.) |

<decisions_made>

- **Determinism is detected, not predicted.** Verification is a byte comparison; no
  static analysis of modules exists or should.
- **The import object is the sandbox.** No allow-list code; the runtime enforces it.
- **Cross-implementation verification is out of scope.** Same module, two nodes.
- **DAG-CBOR at the serialization boundary** forbids `NaN`/`Infinity`/`-Infinity`,
  normalizes `-0.0`, mandates one float width. Protobuf bytes are never hashed —
  protobuf serialization is explicitly not canonical across languages or builds.
- **Own backbone relay is primary**, public IPFS infrastructure opportunistic only.
  Browsers structurally cannot dial most public libp2p nodes.
- **Sovereign data runs redundantly within the owner's own node set** when ≥2 of their
  nodes are live; owner-attested otherwise. The aggregation over contributions is
  what carries the verified claim.
</decisions_made>

  module set from libp2p's own `packages/integration-tests/package.json`.
