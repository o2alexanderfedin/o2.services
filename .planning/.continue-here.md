## STANDING CONSTRAINTS (`CLAUDE.md`'s Conventions carries these with the cost that bought each)

- **Never trust an exit code you did not read directly.** `EXIT=$?` on the very next line, no
  pipes. A trailing `tail` has made a *failing* vitest run report success.
- **Count a plant's own effect before running it.** `perl s///` without `/g` replaces only the
  first occurrence and produced **misleading greens three times** on 2026-08-05 — one mine. **An
  unapplied plant and a green plant are identical in a log.**
- **No backticks inside a double-quoted `git commit -m`** — the shell command-substitutes them and
  silently eats the text. It cost a measured value from a commit message; amend through `-F <file>`.
- **Never `git commit -F -`** — it deadlocks holding `.git/index.lock` against every agent.
- **Commit with explicit paths**, never bare; verify with `git show --stat`.
- **After any abrupt agent death, `git diff` production files FIRST.** A plant is uncommitted by
  construction, invisible to `git log`, and looks exactly like work. (Checked on 2026-08-06 after
  a session-limit kill: clean.)
- **Prefer comparative readings to absolute ones; measure the process, not the machine**
  (`/usr/bin/time -p`, `(user+sys)/real`). Load average lies — 0.34 share at load 226.
- **A ratio between a measured span and a CONSTANT is only load-proof if the span is.**
- **A duration equal to a timeout is evidence of the timeout**, not of the thing measured. Seen
  three times now: `lift`, `#63`'s 60 s, and `late-combine`.
- **"Passes in isolation" is a claim to verify, not a diagnosis.** One recorded instance was false.
- **A proof that cannot fail is not a proof.** Plant, watch it redden, restore, record the text.
- **Descoped is not satisfied; unmeasured is not met.**
- **Cite by grep-able symbol, never line number.**
- **Do not kill or signal any process you did not start.** A foreign `transpilers/cpp-to-rust`
  clang++ build and OrbStack held this host at load 68 on 5 August and were left alone.
- **Do not run `gsd-sdk query state.*`** — it has corrupted `STATE.md` three times without erroring.
- **ALL NODES HAVE EQUAL FUNCTIONALITY. Only discovery differs.**
- **The repository is PUBLIC and the owner accepted disclosure 2026-08-04.** US provisional
  deadline **2027-07-26**.
