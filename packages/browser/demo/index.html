Workload A · Pythagorean-triple 2-colouring

Capacity grows with participants, and it grows in steps.

The job

Colour every whole number from 1 to N red or blue so that no three numbers with a² + b² = c² end up the same colour. The search is split into independent cubes and spread across this tab and every peer it can reach. With a peer connected, every cube is run on two of them and the two must agree; alone, this tab runs each cube once. The report below says which happened, and how far that goes.

N climbs until the fabric cannot settle a rung. Each cube fixes the colours of the most constrained numbers and searches the rest, so more cubes reach further — with more peers connected, more cubes run, and the answer gets better. N = 7824 is the largest that admits a colouring at all; 7825 does not, which took a cluster and a 200-terabyte proof to establish. This will not get near either.

            The colouring verifier shares an author with the fabric, so a misconception
            held in both is invisible to the pair. π(x) was tabulated in the mathematical

Why this surface has no run control

          

          

            The module is here and it runs — in the Node test suite, and in the recorded run
            the figures below come from. What is missing is a signed record a tab's executor
            would accept, and minting one means a new trust anchor for every kernel this
            project ships. That is a decision about the trust root rather than a wiring job,
            it is stated in the interface contract as an open question, and it is not taken
            on this page.
